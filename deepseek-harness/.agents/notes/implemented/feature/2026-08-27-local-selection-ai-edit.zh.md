# Agent Note: 文档局部 AI 编辑上下文

Status: implemented

## 问题

短剧工作台此前无法将精确的文本选区带入现有对话编辑器。用户必须手动复制文本，也无法明确选择使用当前项目对话还是新建项目对话。

## 决策

编辑器为 CodeMirror 与 Milkdown 提供统一选区描述，包含文本、字符偏移、从 1 开始的行范围和视口坐标。工作台保存选区快照，并显示带指令输入框及当前/新会话明确操作的受限浮层。操作经既有 conversation input service 把格式化的文件/范围/选区块追加到目标 Session 草稿，绝不自动提交。新会话操作会在当前 Workspace 中创建独立 Session、打开它，然后执行相同的草稿交接。

## 考虑过的替代方案

**立即提交。** 未采用，因为选中文本不应隐式发起模型请求，并且用户应能审阅指令。

**建立第二条聊天传输链路。** 未采用，因为这会绕过既有 Session 日志与编辑器状态；该能力使用既有的 scope-addressed input service。

## 后果

用户发送编辑器草稿后，模型即可获得选区上下文，且可从已记录的 prompt 中重建。编辑器 UI 新增少量本地浮层状态，runtime Session contract 暴露独立创建 Session 的能力以支持新会话动作。diff 预览与文件写回仍使用 Agent 既有工具流程；本变更只提供精确上下文与草稿交接。

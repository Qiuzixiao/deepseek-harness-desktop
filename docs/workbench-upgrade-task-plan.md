# 工作台升级任务计划

最新范围调整：用户取消专注写作模式，已删除入口、状态和隐藏面板样式；保留面板宽度记忆。文件搜索保留在左侧文件树工具区；正文搜索按 VS Code 交互由编辑器内的 `⌘F/Ctrl+F` 浮层承载，编辑器顶部不增加常驻搜索按钮。下文历史记录中的专注模式不再属于待交付范围。

状态：任务已拆分，尚未代表功能完成。范围：对话确认的 1–6 项优化；以可视化写作为主。所有任务按现有授权自主实施，设计细节沿用工作台样式，不引入外部任务平台或额外依赖作为默认前提。

## 实施原则

先验证编辑历史，再补内容保护和文件同步，最后扩展写作工具。每个任务包含用户操作、必要的持久化/API、错误反馈与验收；按纵向功能交付。已存在的未提交编辑器和工具栏修改作为当前基线保留，不覆盖。每项完成后记录测试结果和已知限制；不把组件测试等同于桌面实机验收。

### W01 保存状态与离开保护

状态：核心保护已实现，桌面真实退出与保存状态位置仍待整体验收。依赖：W00。类型：自主执行。

### W03 外部修改检测与冲突保护

状态：待执行。依赖：W01、W02。类型：自主执行。

- 文件被删除、改名或无权限时保留草稿并反馈；正在中文组合输入时不替换编辑内容。
- 验收：Agent/外部编辑修改文件、本地同时编辑、旧保存请求、后台标签更新都不会无提示覆盖；冲突解决后恢复正常保存。

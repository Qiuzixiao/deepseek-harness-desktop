# PRD-04：创造模式与自定义 Agent

状态：提案

## Problem Statement

用户不仅想使用系统提供的短剧 Agent，还希望创建适合自己的短剧 Agent、小说 Agent 或其他创作 Agent。单纯让用户填写一段超级 Prompt，会把领域能力、工具权限、Skill、交互方式和个人偏好混在一起，难以理解、难以修改，也容易产生越权配置。

## Solution

创造模式以自然对话帮助用户定义一个 Agent 的组成。用户可以表达目标：

> 我想做一个小说 Agent，帮我整理世界观、人物关系和章节结构，但不要主动替我决定剧情。

系统通过少量必要问题确认领域、工作对象、默认 Skill、输出类型和需要用户介入的情况，然后生成可预览、可测试、可保存的 Agent 配置。

Agent 配置由几个清晰部分组成：身份和用途、领域 Profile、可用领域能力、挂载 Skill、交互偏好、自动处理范围、需要询问的重大事项和版本信息。用户可以复制、修改、停用或应用到项目。

## 真实使用场景

用户：

> 我想要一个短剧 Agent，重点是人物冲突和对白，不要替我决定结局。它可以自动整理人物和场景，但重大反转要先问我。

系统展示配置预览：

- 领域：短剧；
- 关注：人物冲突、对白、可拍性；
- 可用能力：项目读取、场景草稿、短剧格式检查、版本提交；
- 参考 Skill：用户选择的写法 Skill；
- 必须询问：重大反转、人物底层动机改变、结局方向、正式提交；
- 不允许：项目外读取、任意 Shell、绕过版本写入。

用户测试一段任务后说：

> 以后默认把这个 Agent 用在新建的短剧项目里。

系统保存配置并记录版本，不改变已有项目。

## User Stories

1. 作为编导，我希望通过描述目标创建 Agent，而不是手工编写一大段 Prompt。
2. 作为编导，我希望选择短剧、小说等领域，以便 Agent 使用正确的项目对象。
3. 作为编导，我希望指定 Agent 重点关注人物、节奏、对白或世界观，以便得到符合目的的建议。
4. 作为编导，我希望选择要挂载的 Skill，以便组合自己的知识和写法。
5. 作为编导，我希望规定哪些事情自动完成、哪些事情必须问我，以便保留创作控制权。
6. 作为编导，我希望在保存前预览 Agent 的组成和权限，以便知道它会做什么。
7. 作为编导，我希望先用一条示例任务测试 Agent，以便发现配置不合适的地方。
8. 作为编导，我希望把 Agent 应用到指定项目或设为默认，以便控制使用范围。
9. 作为编导，我希望复制已有 Agent 再修改，以便快速建立不同用途的版本。
10. 作为编导，我希望停用、更新和恢复 Agent 配置，以便安全迭代。
11. 作为编导，我希望 Agent 的创作建议不能覆盖我明确的选择，以便保持作者权。
12. 作为编导，我希望不能通过创造模式授予 Agent 项目外访问或任意执行权限，以便保证安全。
13. 作为编导，我希望区分短剧 Agent 和小说 Agent 的对象和校验，以便避免只换名字不换能力。

## Implementation Decisions

- 创造模式的结果是声明式 Agent 配置，不是可执行代码，也不是不可解释的长 Prompt。
- Agent 配置至少包含：名称、描述、领域 Profile、领域能力集合、Skill 引用、交互偏好、适用范围、版本和状态。
- 领域 Profile 提供可用项目对象、领域工具和客观校验；短剧与小说使用不同 Profile，但共享 Harness 的会话、权限和版本基础设施。
- 用户偏好只能选择系统允许的交互和创作范围，不能添加通用文件越权、网络访问或任意代码执行能力。
- 创造模式先生成预览和测试草稿，用户明确保存后才成为可调用 Agent。
- Agent 可以绑定用户作用域、项目作用域或仅当前会话；默认采用当前用户明确选择的范围。
- Skill 以引用方式挂载，不复制内容；Skill 更新后，Agent 可以显示待更新状态并由用户确认。
- Agent 运行时仍遵循用户当前明确指令、项目事实和系统硬不变量的优先级。
- 重大创作分叉、正式提交、删除和恢复等动作由领域工具和用户确认控制，不由 Agent 配置绕过。
- 运行日志记录使用的 Agent 配置版本和 Skill 版本，便于复盘结果。

## Testing Decisions

- 验证用户用自然语言创建短剧 Agent 和小说 Agent 后，领域工具、对象和校验不同。
- 验证配置预览准确展示 Skill、作用域、自动处理范围和需要询问的事项。
- 验证示例任务使用的是草稿或沙盒结果，不会修改正式项目。
- 验证保存、复制、更新、停用、恢复和删除的版本行为。
- 验证 Agent 配置无法增加项目外路径、通用写入、Shell 或其他未授权能力。
- 验证用户当前明确选择覆盖 Agent 的默认偏好。
- 验证挂载 Skill 的版本可追踪，Skill 停用后不会继续自动加载。
- 验证同一 Agent 在中断后恢复时仍使用正确的配置版本。

## Out of Scope

- 用户编写和上传任意可执行 Agent 代码。
- 模型微调、自动训练和跨用户共享 Agent。
- Agent 市场、付费、排名和社区分发。
- 用一个通用 Prompt 模拟所有领域的工具和校验。
- 创造模式替用户决定题材、审美、人物走向或结局。

## Further Notes

创造模式的目标是让用户组合能力，而不是让用户成为 Prompt 工程师。用户描述“我想让它怎么帮我写”，系统负责把这句话转换成可解释、可测试、可撤销的 Agent 配置。

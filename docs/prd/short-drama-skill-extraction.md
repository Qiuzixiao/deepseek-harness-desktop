# PRD-01：从已完成项目沉淀可复用 Skill

状态：提案

## Problem Statement

用户完成一部短剧后，项目里积累了大量有价值的修改和取舍，但这些经验只能留在这一个项目中。用户如果想复用，通常只能复制整部剧、手写提示词，或者凭记忆告诉 Agent 自己以前怎么写。

直接把整部剧复制成 Skill 会混入人物姓名、情节事实和一次性的写法，既不利于复用，也不能证明其中任何做法适合所有项目。

## Solution

用户可以在完成项目后用自然语言提出：

> 从这个项目里总结我反复保留的写法，做成以后可以参考的 Skill。

Agent 从项目正式版本、版本差异、用户明确确认过的修改和用户选择的案例中提取候选经验，并把内容分成：

- 可复用的写法偏好；
- 可复用的创作流程；
- 可复用的检查问题；
- 只属于本项目的故事事实；
- 证据不足、需要用户判断的推断。

Agent 先展示候选内容、来源和适用范围。用户选择后才生成 Skill。生成的 Skill 是参考资料，不是系统硬规则，也不能获得额外权限。

## 真实使用场景

用户：

> 这部剧我已经写完了。帮我看看哪些是我自己的固定写法，但不要把这部剧的故事内容带进去。

Agent：

> 我找到 6 个可能重复出现的写法，其中 3 个在多个版本中被你保留，2 个只出现过一次，1 个属于本项目人物设定。我先展示前 3 个，是否要把它们做成参考 Skill？

用户选择后：

> 保留冲突通过人物选择推进、台词少解释、多留信息差这三点。

系统生成一套带来源说明的 Skill。下次用户可以说：

> 新项目可以参考我从上一部剧沉淀的写法。

## User Stories

1. 作为编导，我希望从已完成项目发起 Skill 提炼，而不必手工整理所有文件，以便复用创作经验。
2. 作为编导，我希望看到每条候选经验来自哪些版本或修改，以便判断 Agent 是否理解正确。
3. 作为编导，我希望把故事事实和通用写法分开，以免人物和情节被错误复用。
4. 作为编导，我希望逐条选择要保留的经验，以便掌握 Skill 的内容。
5. 作为编导，我希望给 Skill 指定名称、说明和适用题材，以便以后找到它。
6. 作为编导，我希望看到 Skill 的不确定性和限制，以免把一次项目经验误认为普遍规律。
7. 作为编导，我希望修改生成的 Skill 内容，以便纠正 Agent 的归纳。
8. 作为编导，我希望取消提炼而不影响原项目，以便安全试用。
9. 作为编导，我希望把 Skill 设为只在指定项目或指定 Agent 中使用，以免影响其他创作。
10. 作为编导，我希望在新项目中临时停用这套 Skill，以便尝试不同写法。
11. 作为编导，我希望后续更新 Skill 时保留旧版本，以便比较和恢复。
12. 作为编导，我希望提炼过程不会自动提交或修改正式剧本，以便保持项目稳定。

## Implementation Decisions

- 提炼入口采用自然语言；界面可以提供快捷入口，但不把复杂表单作为主入口。
- 提炼证据只来自用户明确授权的项目内容、正式版本差异和用户确认记录。未授权的参考文件不自动纳入。
- 候选内容必须带来源、置信度或证据说明、适用范围和已知例外。
- 提炼结果先进入 Skill 草稿，不直接安装。用户确认后才生成可用 Skill。
- Skill 至少包含名称、描述、适用范围、参考内容、来源说明和版本信息。
- 生成器必须过滤项目名称、角色姓名、专有情节、连续性状态等一次性事实，除非用户明确要求保留为案例。
- 用户选定的内容优先于模型归纳；模型不能把“出现过”表述为“用户固定偏好”。
- Skill 只能影响 Agent 的建议和工作方式，不能改变项目路径、工具权限、版本规则或提交条件。
- 生成、修改和发布 Skill 都应是可撤销的独立操作，不改变原项目版本。
- 后续可把多个项目的用户确认经验合并为一套 Skill，但第一版只处理单个项目。

## Testing Decisions

- 测试应从用户输入和最终 Skill 内容验证行为，不测试模型内部使用了哪种抽取算法。
- 使用包含多次版本修改、用户保留和用户否定内容的项目样本，验证候选分类和来源展示。
- 验证项目专有事实不会自动进入通用 Skill。
- 验证用户取消、部分选择和修改候选后，原项目正式文件不变化。
- 验证生成的 Skill 可以在指定项目或 Agent 中启用，在其他作用域不可见或不自动匹配。
- 验证 Skill 建议不能绕过项目作用域、写入权限和提交校验。
- 验证 Skill 版本更新、恢复和重复操作不会产生重复或丢失。

## Out of Scope

- 自动判断某种写法“正确”或“适合所有题材”。
- 无用户确认地从全部历史项目自动学习长期文风。
- 把整部剧、全部参考资料或所有对话原样复制成 Skill。
- 训练新的模型或改变模型权重。
- Skill 之间的自动合并和冲突裁决。

## Further Notes

这项能力的价值不在于自动生成一段更长的 Prompt，而在于把用户确认过的经验变成可查看、可修改、可停用、可追溯的参考能力。

# Creative decision prompts

These are questions for clarifying intent, not rules for writing:

- What must the audience understand or feel at the end of this scene?
- Which character is choosing, and what alternative are they refusing?
- Is this change a user-approved project fact or only a proposed direction?
- If two story directions are viable, what trade-off matters to the user?
- Does the user want analysis, alternatives, a draft, or a formal commit?

Ask only when the answer changes the story direction, a project fact, or an
irreversible operation. Do not ask the user to resolve mechanical format
errors that the domain validator can repair.

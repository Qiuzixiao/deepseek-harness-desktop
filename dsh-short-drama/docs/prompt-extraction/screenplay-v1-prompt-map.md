# screenplay-v1 Prompt 抽取图

本文只记录现有 Prompt 中的职责归属，不把任何参考材料当作正确方法。

## 保留在运行时 Prompt

- Agent 身份和当前 Session 的项目作用域；
- 项目事实、用户选择、Skill 建议、模型推断的区别；
- 项目内普通文件操作和元数据保护边界；
- Skill 自动匹配、按需加载和来源诚实；
- 观察、调用工具、读回、修正的开放循环；
- 重大创作分叉、重大未知和不可逆操作的用户介入规则；
- 工具结果必须诚实，失败不得伪装成成功。

## 移出运行时 Prompt

| 现有内容 | 新归属 | 处理方式 |
| --- | --- | --- |
| M1-M7 方法论正文 | 可选 Skill reference | 只能作为参考，不得成为系统错误或默认审美 |
| 固定阶段状态机 | 删除 | 当前 Agent 不维护创作状态 |
| 固定确认话术 | 删除 | 仅创作分歧和删除操作需要询问 |
| 正文和 Artifact 模板 | 可选 Skill | 不作为代码写入门槛 |
| 诊断清单 | 可选 Skill | 只给建议，不阻止文件操作 |
| 通用文件读取禁令 | 作用域工具组合 | 读/搜可用，但只能访问当前项目 |
| 长篇示例 | 文档或测试 fixture | 不进入每轮 Prompt，也不产生项目事实 |

## 参考资料抽取原则

用户资料只抽取以下信息：

- 短剧领域概念和可选工作方法；
- 每个对象的输入、输出、前置条件和停止条件；
- 需要用户决定的创作问题；
- 可复用但不阻断创作的检查建议；
- 不能机械验证、应交给 Agent/Skill 讨论的质量问题。

不抽取为系统规则：

- 某个作者的固定写法；
- 对钩子、反转、情绪或商业性的唯一答案；
- 任何要求所有编导遵循的风格模板；
- `short-drama-zonggang` 的原文正文或原样 references。

## 验证

Prompt 测试只验证运行时身份、作用域、用户权责和循环规则存在，并验证 M1-M7、固定话术、通用读取禁令和统一审美没有重新进入 Prompt。创作质量不通过字符串快照测试认证。

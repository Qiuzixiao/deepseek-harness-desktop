# Story Review

审校默认只写报告，不直接覆盖正文。先读取项目合同、brief、相关 Bible、大纲、当前正文和已有审校；按本轮范围审查，不把全项目无差别塞入上下文。

## 检查项

- 项目结构、文件命名、集/章编号和必要引用；
- 人物目标、能力、关系、秘密、行为和弧光是否互相冲突；
- 年龄、时间、地点、道具、时代事实和资源获得过程；
- 大纲目标是否在正文兑现，伏笔是否有前置和回收；
- 短剧的开场钩子、单集目标、冲突升级、反转、爽点、卡点和下集钩子；
- 小说的视角、章节目标、信息增量、节奏、伏笔和人物成长；
- 台词是否符合人物身份，叙述是否符合项目风格，参考材料是否被不当复写。

## 报告格式

报告写入 `reviews/`，每项包含：严重度（阻塞/高/中/低）、问题、证据文件和位置、影响、修改建议、是否需要用户决定。先列阻塞和高风险问题，再列可选润色。修改完成后重新审查相关范围，并保留原报告，不抹掉历史判断。

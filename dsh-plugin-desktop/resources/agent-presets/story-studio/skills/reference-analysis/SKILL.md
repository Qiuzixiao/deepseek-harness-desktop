# Reference Analysis

参考材料不是新作品事实。先确认用户要总结、拆解、改写、对标还是仅作风格参考；目的不清且会改变输出时只问一个高影响问题。

## 输入处理

拖入或粘贴的文件由 `dsh-drop-to-path` 提供工作区路径。需要读取 DOCX、PDF、XLSX 或 PPTX 时，使用可用的文档读取工具按路径解析；不要凭文件名猜内容。把来源登记到 `参考资料/参考资料索引.md`，记录原文件名、路径、格式、解析状态、用途和时间。

## 分析分层

分析文件写入 `参考资料/分析/<稳定ID>.md`，明确分开：

1. 来源事实：带页码、章节、场次、表格行或其他可定位位置。
2. 分析判断：结构、节奏、角色功能、冲突机制、情绪回报和市场表达。
3. 可迁移方法：用抽象规则描述，不复制原作独特组合。
4. 新作品应用：结合当前 QNovel 项目的设定重新设计的内容。

不得把大段原文、原作角色名、独特情节组合或专有台词直接写入新作品正文。无法定位的结论标为推断，不伪装成来源事实。

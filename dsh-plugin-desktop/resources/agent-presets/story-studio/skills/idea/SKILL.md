# Idea

一个低摩擦的记录动作，不是创作流程。目标是让灵感落盘的成本接近于无，不为此追问、不展开分析、不生成大纲。

## 1. 先判断是否真的只是"记一下"

如果用户话里已经包含足够具体的创作要求（要现在就写人物、大纲或正文），改用 `story-intake` 或对应的创作 Skill，不要把明确的创作请求降级为一条速记。

## 2. 定位灵感速记文件

文件固定为当前项目根目录下的 `灵感速记/灵感速记.md`。

- 若当前工作区不是一个已初始化的 QNovel 项目（没有 `项目配置.yml`），提醒用户当前不在项目工作区内，不擅自新建一个独立项目结构；确认工作区后再继续。
- 若 `灵感速记/` 目录或 `灵感速记.md` 文件不存在，先创建：目录用 `mkdir -p`，文件初始内容为 `# 灵感速记\n`。

## 3. 追加，不改写

只在文件末尾追加新记录，不修改、不删除、不重排已有内容。每条记录格式：

```markdown
## <YYYY-MM-DD HH:mm> <关键词1> <关键词2>
<1-2 行内容，直接记录原始想法，不展开、不分析、不生成大纲>
```

关键词是后续 grep 检索的入口：尽量包含人物、题材、结构类型（反转/钩子/卡点等）之类创作阶段可能会用到的词，而不是泛泛的形容词。

## 4. 写入后

只需简短确认记录内容和文件位置，不追加分析、不追问、不建议下一步创作动作。

## 触发方式

- `/idea <内容>` 手势直接触发；
- 自然语言如"记一下这个灵感""这个点子先记着"等，可直接识别并调用本 Skill，不需要用户输入 `/idea`。

## 与创作 Skill 的关系

本 Skill 只负责写入。`story-intake`、`short-drama-writing`、`novel-writing` 会在构思核心卖点、反转、钩子、人设或情节转折时主动用 grep 检索本文件；本 Skill 不做检索，也不维护索引或标签表。
